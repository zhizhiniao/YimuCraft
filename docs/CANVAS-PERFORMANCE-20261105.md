# 大画布多选拖动优化

日期：2026-11-05（America/Denver）。源码和本机安装均为 0.7.65，已从系统桌面入口重开，恢复原 Data 画布。用户拖动手感待验；未公开发布。

## 改动和依据

- 多选直接走画布指针事件；旧版图片多选进入系统文件拖放，受 dragover 频率和外拖最多 100 文件的限制。单图外拖保留；批量外拖改用 Alt + 拖动。
- 选中元素及组内后代临时放入同一 DOM 层，每帧只更新一次层位移。保留图片、文字和事件；松手写入坐标并移回，取消或保存失败回退。
- 连线路径复用，只改坐标；不重新创建 SVG、标题、图标或图片。仅当前移动层临时启用 will-change，结束即清理。
- 分组候选一次筛选、排序，前端命中检测和后端提交复用，消除每个元素重复全库扫描。后代随组移动，松手自动归组。
- 框选缓存本轮可见几何，每帧合并更新，只改选中状态发生变化的元素；抬手补算最后坐标。丢失捕获、Esc、切换工作区清理手势。

## 前后测量

隔离 Electron、3,000 个真实可解码 PNG 文件、同一布局和缩放，拖动含 600 张图片的分组，共 40 次采样。截图已检查。

| 指标 | 原 0.7.64 | 优化源码 |
|---|---:|---:|
| DOM 变更记录 | 240,839 | 347 |
| 内容变更记录 | 48,080 | 0 |
| 整个连线 SVG 重建 | 40 | 0 |

新版将部分处理延后至 requestAnimationFrame；同步耗时不是完整帧耗时，不宣称整体快 21 倍。隐藏窗口的帧调度约 1 秒，不能评价真实显示 FPS。未对 PureRef 同机计时，用户操作手感待实际试用。

证据：旧版 `work/canvas-performance-1793929923611/report.json`；优化分组 `work/canvas-performance-1793930016202/report.json`。旧版性能及坐标保存有效，但重启总数断言失败：扫描产生额外序列记录，夹具错误地只计算图片和组；后续改为比较保存后总记录数，旧失败保留。
