# 类型文件夹修正（0.7.43）

日期：2026-10-23（America/Denver）。此前把需求理解成固定快捷入口有误；本次以用户明确的文件夹创建选项和唯一性为准。

## 行为
- 上方“类型”区域保持空白，去掉四个固定快捷入口。旧 folder-shortcuts.json 保留但不再读取，不替用户自动创建类型目录。
- 点击文件夹旁 + 或文件夹右键“新建文件夹”，先显示 Premiere / After Effects / 图片 / 音频四种类型，普通文件夹排在后面。
- 默认选择第一个尚未占用的类型；名称可以自定义。四类均已占用时默认普通文件夹；普通文件夹不限数量。
- 类型图标出现在下方真实文件夹树。每种类型在整个当前素材库中最多一个，不能在另一个父目录重复创建。
- 已有文件夹可在图标选择器选可用类型；改回普通图标或删除空目录会释放类型。改名、移动、重启保持类型身份。

## 数据保护与验证
- 复用 folder_preferences.icon；schema 1→2 增加 SQLite 部分唯一索引，防止并发/API 绕过界面。迁移前自动留校验过的快照，初始化不创建任何类型目录。
- 重复类型在界面禁用，后端给出已存在位置；并发创建仅一项成功，失败者移除其刚建的空目录，不影响先存在的目录。
- 源码 UI 已通过空白类型区域、真实 mkdir、图标位于树、禁止重复、修改已有图标、重启、改名、删除释放、四类用尽后默认普通。
- 核心 94/94 已通过，包括并发、数据库直接写入拒绝重复和旧版快照迁移。源码最终 run 1792758320874；目录版 run 1792758466343、安装版 run 1792758514820 均通过。
- 已查看真实截图，修正初版新建窗口横向溢出，改两列选项并检查 scrollWidth 不超出 clientWidth。媒体播放/棋盘代码未改，不重复完整媒体链路。

## 失败与边界
- 首次 UI 选择器同时匹配按钮与子图标；改为 button 定位。迁移测试 SQLite 无原型对象与普通对象比较失败，转 JSON 核对实际值，未改变产品数据。
- 补测使用 AE 名称撞到宿主面板已有小写 ae 目录，保留 EEXIST 保护，夹具改为“我的AE”。未覆盖或删除已有目录。
- 每库唯一，非全电脑唯一；类型只是整理身份，不限制存放格式。原有目录不自动归类。原版对照和人工体验仍待验收。
- schema 2 不能直接被 0.7.42 打开；若回退，须保留新库并把升级前 schema-backups 快照恢复到新目录，不能覆盖后续素材变化。

## 经验候选
- 行动：把“图标属于目录”落实到真实 mkdir、树节点及数据库唯一约束；结果：跨父级和并发都不能重复。
- 原因：只隐藏按钮不能保护数据；验收：重复创建/改图标/API/并发均拒绝，改名重启仍唯一；反例：四个固定入口或只按格式筛选。
- 边界：本地当前素材库的四种类型；此条为候选，未经用户确认不升级为已验证通用经验。
