# 画布导航与分组交互（0.7.69）

已在本机安装并重开。左下角增加半透明布局导航；分组名称在框外保持字号，组内空白可选中和拖动，选中后可直接修改名称与颜色。

## 交互与实现

- 导航显示当前筛选范围的全部可见元素及视口；点击定位，拖视口平移，Esc 取消。聚焦后方向键移动，Shift 加大步长，可收起。
- 导航只绘制几何布局与组色，不复制解码媒体；缓存底图，连续平移只更新视口框，结束后再调整总范围。
- 分组标题位于框外，字号 13 px、高度 28 px；标题宽度随组的屏幕宽度收紧，最小 84 px，中文长名称约保留前两字与省略号，悬停显示全名。
- 组内空白点击激活，橙色外框与标题高亮；拖空白或标题整体移动。图片等子元素仍单独选中，嵌套空白选中内组。
- 单独选中组后，底部操作条与右键菜单显示“名称与颜色”；复用原有持久化字段。折叠按钮保持固定尺寸，键盘折叠不会同时打开编辑器。
- 适合窗口为框外标题预留顶部距离；鼠标在标题上时隐藏上方连接点，避免抢走分组拖动。组的四边缩放与连线仍保留。
