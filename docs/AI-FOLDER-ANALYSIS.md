## 从哪里使用

1. 右键左侧素材文件夹，选择“AI 分析与打标…”。确认是否包含子文件夹。
2. 为画面与声音分别选择 API 服务商和模型。当前已实测的视觉配置是 **MiniMax / MiniMax-M3**；声音暂选“跳过此类素材”。服务商复用“AI 设置”的加密凭据，模型 ID 可在本窗口单独填写。
3. 点“先试分析最多 3 项”，查看标签、说明、采样范围和实际 Token 回执。结果自动追加，原标签与用户备注保留。
4. 小样全部成功并核对正确后，点“小样结果正确，解锁批量”，再运行剩余项。
5. 每批默认最多 20 项、100,000 Token 回执预算；上限分别为 1,000 项、2,000,000 Token。可收起、取消、重开后续跑或撤销本次结果。

小样门禁由后台检查同一素材库、文件夹/子目录范围、素材清单及模型配置，不仅依赖按钮是否可点。
取消不保证退回已在服务商发生的费用；Token 预算在收到回执后限制后续请求，并非精确的金额预授权。
后续改过的标签会使该条撤销跳过，避免覆盖用户修改。已完成任务不会自动在下次启动继续发送。

## 实际分析什么

| 类型 | 当前输入 | 范围说明 |
|---|---|---|
| 图片 | 缩放后的真实图片 | 最长边 1024，原件不改 |
| 视频 | 约首、中、尾的 3 帧 | 不声称看完完整视频 |
| 音频 ≤45 秒 | 实际声音整段 | 转为 16 kHz 单声道 WAV 供接口读取 |
| 音频 >45 秒 | 首、中、尾各 15 秒 | 按顺序拼接，段间加 0.5 秒静音分隔，并在请求中说明；不是分析整首 |
| 工程/预设 | 已有真实封面/效果图 | 不分析工程图层与插件依赖 |

模型只收到必要媒体样本与分析指令，不发送素材的磁盘路径、文件名、用户备注或 API 密钥文字。
模型输出只按数据校验和显示，不执行其指令。返回不能读取媒体、内容不合约定或请求失败时不写入该条标签。
连续两条错误停止本批；未成功的声音请求不能靠图片或名称猜测补成“通过”。

- 普通文字搜索包含 AI 内容说明；资料栏新增“AI 内容说明”，不占用用户备注。
- 已下载本地 Chinese-CLIP 时，完成后将生成的说明/标签建立 `ai_text_features` 语义向量，接入“AI 语义”搜索；未下载时仍能普通搜索，不自动下载。
- 本地推理限制为 2 个计算线程；画面索引跳过音频，本地画面标签不再把音频封面当声音内容。
- 未变化的素材和相同分析配置复用已有结果；指纹依赖路径、大小、修改时间、封面与规则版本，不能保证发现人为保持这些属性不变的外部改写。

## 失败与回退

- 首次视觉响应包含 `<think>` 前缀，严格 JSON 解析拒绝；观察真实响应后支持剥离此前缀，媒体不可读声明仍拒绝，不因 HTTP 200 判定通过。
- 界面初验的菜单捕获与波形点击夹具已更正，失败报告保留；最终打包应用通过。普通 Node 直接运行旧测试遇短 TEMP 路径差异，按项目标准工作区 TEMP 回归通过。
- NSIS 多次返回 exit 2，包含旧程序文件卸载失败；后台连接进程占用与 TEMP 跨卷是观察线索，尚不能确认唯一根因。停止安装器重试后，正常退出主程序，备份旧 EXE/ASAR，只终止同路径的 MCP 连接辅助进程，再发布本次验证包内的 EXE/ASAR；Electron/依赖版本未变化。没有宣称 NSIS 安装通过。
- 已有 v4 库曾因迁移版本未递增而缺少新表；正式核验发现后提升到 v5，补旧库回归及快照校验。最终旧库升级通过，早期失败回执保留。
- 正常用户配置与 Codex 配置副本不是同一份；原配置的 MiniMax 实际解密失败。只恢复身份、地址、协议、模型均相同且已成功验证的 Kimi/MiniMax 凭据，在正常程序内重新加密；原文件备份为用户数据区 `model-providers.json.pre-ai-recovery-20261115`。未输出明文密钥，未改变当前服务商或其他配置。
- 程序回退文件位于 `work/ai-analysis-20261115/rollback-program-0.7.78`。索引 v5 不能直接交给旧版；须先在新目录恢复经校验的升级前 v4 快照，再让旧版打开该目录。快照不含升级后的标签变化；新标签需在新版任务中撤销，不能靠降版本自动撤销。

## 经验候选（未确认）

行动：用已知内容的自有图/声音核对 API 回答，并让小样门禁在后台校验。
结果：发现 HTTP 成功但模型未读取声音，阻止错误批量；真实图像流程与持久化通过。
原因：协议接受输入不代表模型实际具备该模态能力。
验收：请求包含真实媒体、独立内容答案、源摘要、重开与重复调用计数；音频服务仍未通过。
反例：以音频封面、文件名猜测或 HTTP 200 冒充听过声音。
边界：本机这几种配置与样本，不代表所有模型或全部音乐质量；未经本人确认不升级正式经验。
