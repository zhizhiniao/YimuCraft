- 移除当前仓库自动切到剩余仓库；移除最后一个进入可继续打开项目的空状态。离线目录保留记录并标示离线，恢复后同步可继续使用。
- 画布搜索集中到“筛选”侧栏；来源内的搜索仅筛选待加入素材。顶部保留镜头、说明、文字、同步、适合窗口和历史记录。
