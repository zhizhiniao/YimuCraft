# 一幕 YimuCraft 0.7.76 · 素材库查找、画布编辑与 PR 后台导入

**Windows x64 开发者预览版**，2026-11-13。[下载安装包](https://github.com/zhizhiniao/YimuCraft/releases/download/v0.7.76-dev.1/YimuCraft.Setup.0.7.76.exe) · [SHA-256 校验文件](https://github.com/zhizhiniao/YimuCraft/releases/download/v0.7.76-dev.1/SHA256SUMS.txt)

本版包含 0.7.75 的 Premiere Pro 导入修复，以及 0.7.76 的找素材和画布改进。

## 找素材：默认查当前素材库

- 打开「找素材」即可搜索当前素材库，也可在下拉框切换已关联的项目。名称、路径、标签和备注都能匹配；横竖屏根据原文件尺寸判断，无须提前打标签。
- 筛选条件集中显示为小标签，历史收进时钟入口，重复点击不会堆出一列过程卡片。「已确认」仅适用于项目中的确认状态。
- 大库分批显示结果，未查完可点「继续查找」。勾选结果后，可对比或加入所选项目的候选组；原文件保持原位。
- 「按画面找」和素材库「以图找」使用已有本地语义索引，须先下载模型并建立索引；项目「以图找」仍按颜色和布局比较。语义识别质量仍待更多验证。

## 画布：直接改字、直接断线

- 新建入口统一为「文字」，已有说明节点继续保留。双击节点即可在原位置编辑，**Ctrl+Enter** 或点击外部保存，**Esc** 取消；颜色在节点下方工具条修改。
- 鼠标靠近连线时出现 **×**，点击即可断开；点选连线后也可按 **Delete**。右键移除方式保留。

## Premiere Pro：连接随宿主启动

一幕启动时自动安装或更新自己的后台连接。**首次升级后，保存工程并重启一次 Premiere Pro**，之后无须手动打开一幕扩展面板。

在 PR 打开目标工程，在一幕选中图片、音频或视频，右键「发送到 Premiere Pro」。支持混合多选；导入成功后自动切到 PR，并选中新增素材。

本机 Premiere Pro 26.0 已验证图片、音频、视频、混合多选、最小化恢复、冷启动和工程重开；其他 PR 版本仍待验证，MOGRT/LUT 本轮未复测。
