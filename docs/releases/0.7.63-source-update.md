# 0.7.63 源码更新 · 2026-10-31

本次把 0.7.57–0.7.63 的本地改动同步到 GitHub。应用版本保持 0.7.63；公开安装包仍为 [v0.7.56-dev.1](https://github.com/zhizhiniao/YimuCraft/releases/tag/v0.7.56-dev.1)，没有新增 Release 或替换旧包。

| 原来的问题 | 本次变化 |
|---|---|
| 项目素材散在文件夹里，缺少可恢复的编排视图 | 新增独立项目画布，关联来源目录并自动同步；支持原比例预览、序列播放、标签、说明、文字与连线，重启恢复项目和视图 |
| 模式切换多，大组边界受限、边缘难调整 | 直接鼠标手势；嵌套/折叠分组，拖入/拖出自动归组；修正组框尺寸限制、边缘命中和连接点遮挡 |
| 不使用联动时，AE 仍每秒遍历全工程 | 改为用户显式刷新后执行一次；普通导入只返回轻量摘要，启动脚本不扫描、不建立重复任务 |
| 发送图片的按键链路失效，外拖依赖临时交接 | 自有助手改用 SendInput；右键可配置发送目标；图片本体使用标准 dragstart 传原文件，取消或外落保留布局，缺失文件和结束状态得到处理 |

画布只引用原文件，删除仅隐藏并可恢复；布局与现有素材库独立保存。操作方法见[使用说明](../USAGE.md)。
