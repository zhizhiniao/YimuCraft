# 一幕 YimuCraft 0.7.83 · 连线避让、绑定标签与节点颜色

**Windows x64 开发者预览版**，2026-11-16。

[下载 Windows 安装包](https://github.com/zhizhiniao/YimuCraft/releases/download/v0.7.83-dev.1/YimuCraft.Setup.0.7.83.exe) · [SHA-256 校验文件](https://github.com/zhizhiniao/YimuCraft/releases/download/v0.7.83-dev.1/SHA256SUMS.txt)

## 画布更新

- 顶部“连线”可选平滑曲线、圆角折线、直角折线或直线。新画布默认圆角，旧画布默认曲线；可对单条线单独设样式，或统一整张画布。
- 单击线可设置单向、双向、反向、无箭头；两条反向线可合并为一条双向线，两段标签文字保留，最多20步连线撤销。
- 双击线/标签可编辑，保存空文字即可隐藏。标签与连线绑定，节点移动时同步更新；标签全局排布，避免遮挡节点和其他连线标签，必要时用引线。
- 连线自动绕开可见节点。移动没有直接连接的节点，也会触发受阻路径重算；展开/折叠分组及缩放时重新检查。直线遇到障碍会改为折线绕行。
- 选中说明/文字节点或分组，底部“颜色”可修改；按住Shift多选可批量改色。文字改字色，说明卡片改底色/标题色，分组改边框和底色，重开保留。

## 验证与边界

- 本机真实流程图45线/36标签，四风格的节点内部穿透及标签互挡计数均为0；打包EXE通过真实障碍拖动的6个中间帧、单个/批量改色、分组折叠/展开、缩放和重开验证。常规源码136项及全部152个src文件与安装一致。
- 避让保持节点位置与关系。完全重叠、指定端口被完全遮住或图规模超过寻路上限时，会提示拉开间距并保留连接数据，暂不绘制穿节点的线。极密集标签可能使用较长外侧引线；不保证线线零交叉或任意图全局最优。
- 旧画布的独立文字节点不会自动识别为连线标签；可在线上填写标签，再自行处理旧标注。本次没有开放画布MCP、增加流程节点形状或自动重排整张图。
- 安装包未签名；此前本机NSIS自动卸载旧文件曾失败，本机以程序文件更新验证。此安装器封装已验证的0.7.83程序，未重复安装器升级或全新机器安装测试，不把封装通过当作安装通过。

## 升级与回退

升级前备份素材库索引、画布数据与原媒体；保存工程，从“文件→退出”完整退出一幕，使用MCP的智能体客户端也先断开连接，再运行安装包。
安装器若提示文件占用或卸载失败，请停止重试并反馈，保留素材库。

0.7.80起可从“帮助→检查更新…”发现此版本，下载后手动安装；0.7.79及更早版需先手动升级一次。旧版已有AI、缓存和引导能力继续保留，真实声音理解仍未完成供应商验收。
本轮不升级索引schema。回退更早索引版本时仍须使用升级前快照恢复到独立目录；索引备份不包含媒体，不能直接覆盖当前素材库。
