# 一幕 YimuCraft 0.7.85 · 说明方框自适应

**Windows x64 开发者预览版**，2026-11-16。

[下载安装包](https://github.com/zhizhiniao/YimuCraft/releases/download/v0.7.85-dev.1/YimuCraft.Setup.0.7.85.exe) · [SHA-256 校验文件](https://github.com/zhizhiniao/YimuCraft/releases/download/v0.7.85-dev.1/SHA256SUMS.txt)

## 本次修复

- 补齐说明方框的内容自适应。0.7.84只覆盖文字节点，说明方框仍使用统一尺寸；现在新旧说明均按实际文字和独立标题调整宽高，短内容收紧，长内容换行增高。
- 修复正文区域为隐藏标题预留高度而造成的文字裁切。输入增删会同步调整，保存及重开保留。
- 手动拖拽尺寸后保留固定宽高，不再在拖动中回弹。选中文字或说明，点底部“适合文字”恢复自动适配，支持多选。

![0.7.85 正常画布中的实际修复效果](https://raw.githubusercontent.com/zhizhiniao/YimuCraft/v0.7.85-dev.1/docs/images/v0.7.85/note-fit-after.png)

## 验证与升级边界

核心187/187；源码与打包应用通过输入增删、保存/取消、真实鼠标拉伸、恢复自适应及重开。原图60个说明方框得到30种不同宽度，全部无裁切；77条连线、58个标签、节点位置、组、颜色与其他内容保持。

安装器内EXE/ASAR与已验收的0.7.85本机包一致。**本轮未执行0.7.85安装器升级/卸载测试**；此前0.7.83→0.7.84仅在本机隔离Windows账户通过升级、默认卸载和重装，不能视为本版安装器已验收。

升级前备份素材库和画布，从“文件→退出”完整退出一幕及MCP连接，再运行安装包。安装包未签名；干净OS、跨盘及所有历史版本未测。0.7.79及更早版本需手动升级一次才有更新提示。

本次未改索引schema及依赖。说明自动宽度上限640，之后换行增高；节点尺寸上限8000，极长文本仍可能滚动，不保证无限文本尺寸。手动固定尺寸可主动恢复自动，媒体和分组不自动缩放；连线避让的既有边界沿用。
