一幕 YimuCraft 更新到 0.7.81 开发者预览版了。

这次主要更新：
• 十步上手引导，介绍素材库、项目画布、找素材，以及本地 AI、API 设置和模型切换。
• 文件夹 AI 分析：先试最多 3 项，确认后批量生成标签和内容说明，并按内容搜索。
• 自定义缓存目录，优化音频波形加载和 MOV 缓存复用。
• 新增启动更新提示和“帮助→检查更新”。

AI 分析需自己的视觉 API，调用可能计费；音频内容识别仍在验证。

0.7.79 及更早版本的用户这次需手动升级，之后才能收到后续提示。安装前请备份并完整退出一幕；若提示旧文件占用或卸载失败，请停止重试并反馈。
