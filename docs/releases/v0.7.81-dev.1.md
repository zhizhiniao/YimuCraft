## 文件夹 AI 分析与自动打标

- 右键左侧文件夹→“AI 分析与打标…”，使用“AI 设置”中自己的 API 服务商，为图片/视频与声音分别选择模型。
- 图片发送缩放后的真实画面；视频取首、中、尾三帧，不代表看完完整视频。先试最多三项，确认小样后才能批量；默认每批最多二十项、100,000 Token 回执预算，可取消、复用结果和撤销本次标签。
- 自动追加标签与独立内容说明，保留已有标签和用户备注。文字搜索可匹配 AI 说明；已有本地 Chinese-CLIP 模型时可建立说明语义索引。结果保存在一幕索引中，原图片、MP3、视频及工程文件不写入标签。
- 使用远程 API 会发送所选媒体样本，并可能产生服务商费用。Token 预算在收到回执后限制后续请求，不是金额预授权；取消不能保证撤回服务商费用。
- 本机 MiniMax-M3 的图片、视频抽帧及两图搜索小样通过。**实际声音理解尚未通过现有服务商验收**，暂无声音模型请选“跳过此类素材”；本版不宣称音乐或音效自动识声可用。

## 十步新手引导

首次运行介绍素材库、项目画布和找素材，随下一步实际切换工作区；继续说明本地 AI 下载/建立索引、API 设置、顶部模型切换、文件夹小样和内容搜索。
支持上一步、下一步、跳过；可打开真实设置面板，关闭后继续引导。完成或跳过会恢复进入前的工作区。从“帮助→新手引导”可随时重开。
旧用户已完成的引导状态保留，升级后从帮助打开即可查看新内容。引导不会自行下载模型、建立全库索引或启动付费调用。

## 缓存和预览

- “偏好设置→文件夹管理”可设置素材库共用的媒体缓存根目录与项目画布独立缓存目录。切换可选择删除、只重建已有缓存或剪切迁移，迁移校验后再提交新引用。
- 音频波形按可见范围请求，试听时加载媒体；不变素材重新导入时保留已有预览，MOV 转换产物可跨重开复用。
- 本地 ONNX 计算线程限制为两条；画面索引跳过音频，不能把音频封面当成实际声音内容。没有全库 CPU 降幅或所有文件系统性能的结论。

## 更新提示与升级方式

0.7.80 起默认启动后查询官方公开版本，成功后一天内不重复检查；新版本显示提示，可关闭自动检查或跳过该版本。“帮助→检查更新…”支持手动检查，下载按钮打开官方版本页，安装仍由用户执行。

**0.7.79 及更早版本没有检测代码，无法自动收到本次提示。请先手动安装一次本版，之后才能收到后续版本提示。**

升级前请备份素材库索引、画布数据与原媒体；索引备份不包含媒体。保存工程并从“文件→退出”完整退出一幕，使用 MCP 的智能体客户端也应先断开连接，再运行安装包。

索引升级到 **v5** 前会生成并校验库内 `schema-backups/pre-v*-to-v5-*.sqlite` 快照；回退到使用旧索引结构的软件时，必须将升级前快照恢复到新目录，不能直接用旧软件打开 v5。快照不包含升级后的标签等变化，勿覆盖当前库。
