# 找素材与候选组（0.7.72）

用户要求将精简版 UI 落到正式代码。“找素材”紧接“项目画布”，无分隔线；对话、条件、结果和所选操作各保留必要控件。状态以 HANDOFF 为准。

## 已实现范围

- 本地项目仓库：按名称、路径、标签与说明查找，支持连续追加关键词、排除词、类型、横竖屏与确认状态；条件可删、可退回，查找历史按仓库保存。
- 工具：以图找、筛选、斜杠命令、历史、新查找、全选、排序与网格密度；所选素材支持预览、2–4 项对比和加入候选组。
- 筛选不清空上轮选择；操作栏注明不在当前结果内的已选数量。一次最多选 200 项；新增候选引用及组在同一次事务中保存，原节点位置与源文件不变。
- 候选引用跟随源路径、修改时间和缺失状态；刷新不重复扫描引用，不把引用混入序列帧。入组前核验原文件，失败保留组名与选择。
- 输入支持 Enter 查找、Shift+Enter 换行、空输入 `/` 打开命令；对话框可用 Escape 关闭，预览支持左右方向键。

## 检索边界

- 当前范围是**本地项目仓库**，不是“素材库”工作区的全库索引。下拉选择已关联仓库；选择仓库也会切换画布当前项目。
- 对话使用可见的本地条件规则，不是大模型理解。没有标签或相关名称的“自然光、生活感”等概念不会凭图像自动识别；不自动调用云端模型。
- 以图找复用现有像素相似度算法，以 8×8 RGBA 的颜色和布局排序；不是 CLIP 语义检索，不作置信度承诺。最多分析当前范围内 500 张图片，失败数量明确显示。
- 比较最多 4 项；候选组最多 200 项。同名候选组可分别创建，不隐式合并。序列可复用原预览，须先在画布展开后再选择帧入组。
- 查找记录保存在本机当前配置的浏览器存储；候选组保存在项目画布数据。撤销新增候选组仅当前会话有效；成员变动后拒绝旧撤销。
- 未新增云端服务、模型下载、媒体上传、付费请求或公开发布。既有“素材库”的本地语义入口仍独立。

## 回退与后续

回退应用可使用 0.7.71 本机安装器，升级前画布数据副本在本轮 install 证据目录。不要用旧副本覆盖升级后的新编排。旧版不理解候选引用，已经创建候选组的项目不应直接用旧版继续编辑。

本轮完成界面与真实文件流程；通用语义检索、AI 请求质量、大库以图找性能和用户实际手感仍未验证。
