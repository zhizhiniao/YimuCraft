## 数据流与工程检查

- IPC 复用主窗口/主 frame 身份检查；渲染层不直接联网，原 CSP 不扩大。响应只用 textContent 显示。
- 配置保存在 userData/model-providers.json，Key 经 Electron safeStorage 加密，不进入偏好、素材库或 MCP 工具。系统加密不可用则拒绝保存 Key。
- Key 与精确基础地址/协议绑定；修改地址或协议时清除旧 Key。远程只允许 HTTPS，本机回环允许 HTTP；禁止 URL 内凭据、query、fragment 和网络重定向。
- 用户点「发送试用」才发送输入文字，不附带素材；单请求最多输出 256 tokens、45 秒超时、2 MB 响应上限、不自动重试。取消不能保证服务商停止计费。
- 服务商错误只显示 HTTP 状态和本机提示，不显示远端原始错误体。缺少模型列表时可手工填 ID。
- 无登录/多用户/云同步/数据库迁移；检查范围为凭据、第三方请求、IPC、表单状态、响应显示、回归与安装。未扩展企业功能。
