## 0.7.60 直接手势（历史；连接点规则已由上方替代）

- 中键或右键按住拖动直接平移，从图片或空白处都可开始；右键轻点仍打开菜单。空格加左拖保留，滚轮缩放保留。

- 也可点击连接点再点目标；双击空白处直接创建说明。右键连接线可移除；连接方向与新内容重启后保留。
- 复用已有 Panzoom/interact.js，无新增依赖；参考 [React Flow 设计工具手势](https://reactflow.dev/learn/concepts/the-viewport) 与 [拖线创建节点示例](https://reactflow.dev/examples/nodes/add-node-on-edge-drop)，未迁移 React 或复制整套编辑器。
- 本轮范围为 Windows 鼠标交互；触控屏多指手势未专项验收。外部文件拖入目标应用的旧未验收状态保持。

## 现有操作与默认值（0.7.59 起）
- 重开一幕自动恢复上次工作区、项目地址、筛选和视图；切回素材库后退出，下次则打开素材库。已有 v1 画布首次升级自动保留副本并迁移。
- 左侧“素材来源”显示关联目录，可选文件、加来源文件夹；原件只被引用。开启“新素材自动加入”直接上画布，关闭后进入待选列表，勾选再加入。
- 同目录、相同前缀/格式/编号位数、至少三张连续编号的图片自动合成序列卡；默认 24 fps，双击可播放、逐帧、拖进度及改帧率。v01 等版本后缀不合并；右键可展开或重新合并。
- 图片和可读尺寸的视频按原比例初始显示；已有手动尺寸保留，预览窗口可恢复原比例。名称、标签、尺寸改为悬停或选中说明，无常驻底部信息栏。
- 空白拖动框选，Shift 追加；空格按住平移，滚轮缩放，F 适合窗口。Ctrl+G 或选中条“元素编组”；双击预览编辑标签，拖入/拖出自动调整所属组。
- 组标题拖动整组及其后代，双击修改名称/颜色；四边和右下角调整尺寸。再次编组形成嵌套；右键解组保留内容。
- 选中元素后移到边外，拖动出现的连接点；图片、组、说明和文字都可连接。右键连线可移除。
- 顶栏“说明”“文字”添加纯文本元素，双击编辑；位置、尺寸、内容、颜色与连线按项目保存。
- Delete 和右键隐藏仅影响画布；历史记录可恢复。隐藏组会同时遮住其后代，恢复组后重新显示；明确隐藏的子项仍保持隐藏。
- 原文件拖出入口继续保留；序列拖出为原始帧文件，最多 100 个，不生成 MP4。Codex／即梦的实际 drop 接收仍未验收。

## 基础使用
- 顶部“项目画布”→粘贴项目绝对路径→“关联路径”，或使用“浏览文件夹”。原素材不复制进素材库，原库分类不改变。
- 同一目录只建一份画布；多个路径可在顶部切换。仅当前项目保持目录监听；应用关闭期间新增的素材，下次打开重新扫描。
- 文件写入稳定约 1 秒后触发同步；事件合并约 0.7 秒。大量文件或磁盘繁忙可能更久；“同步”可以手动核对。
- 自动识别路径里的 K00/K01/K02B 等编号；无法识别时放入共享参考或未分镜。编号是初始分类，不表示作品已验收。
- 拖图片移动；Shift 点击多选；右下角缩放素材；滚轮缩放画布；空格加拖动平移。“适合窗口”展示当前筛选结果。
- 选中后可标为已确认／未确认、设置镜头。状态与位置独立保存，新图不会替换已确认图或重排旧图。
- 从画布删除／Delete 只设隐藏记录；“历史记录”可搜索、查看最近删除或恢复时间，并恢复原位置与状态。没有永久删除源文件入口。
- 双击预览图片／视频／音频；工程提供原文件入口。Remotion 的项目 package.json 显示为工程，进入所在目录继续编辑。
- 旧版专用拖出按钮已在后续版本移除；当前直接从图片本体拖出原文件，一次最多 100 项，操作见本文顶部。
- 不支持拖放的目标可使用“查看→复制原路径／所在文件夹”。目标应用支持的格式和上传限制仍由该应用决定。

## 复用选择
| 开源代码 | 本次用途 | 取舍 |
|---|---|---|
| [Panzoom](https://github.com/timmywil/panzoom) · MIT | 视图平移、缩放 | 适配现有原生 JS 与 DOM，不引入 React |

| [Chokidar](https://github.com/paulmillr/chokidar) · MIT | 递归目录监听、写入稳定判断 | 4.0.3 与现有 CommonJS 主进程兼容 |
| [Konva](https://konvajs.org/docs/faq.html) · MIT | 本轮未采用 | 能做画布，但当前 DOM 缩略图与系统拖出更容易复用 |
| [tldraw](https://tldraw.dev/community/license) | 本轮未采用 | 当前 SDK 生产环境需单独许可，不作为 MIT 可直接替换组件 |

## 存储与边界
- 画布记录保存在当前 Electron userData 的 `project-canvases/projects.json`；原子替换并保留上次 `.bak`。缩略图位于相邻 `thumbnails`，不写入被关联项目。
- 布局、确认状态与隐藏历史均按项目隔离；元数据备份不包含媒体。源文件真正被移动出目录或删除时，卡片显示缺失，画布恢复无法重造源文件。
- 同磁盘可识别的单一文件重命名保留状态；跨磁盘搬迁、同内容副本不保证继承身份。重命名与内容更新不等于版本已确认。
- 忽略 node_modules、.git、.venv、缓存与 evidence 等目录及符号链接；单次最多 2 万素材／10 万目录项。达到限制会提示，不把未扫到的项标为丢失。
- 仅关联路径中的图片、视频、音频、常见工程和文档进入画布；纯代码、日志与任意附件不自动铺满画布。
- 缩略图按视野请求并串行缓存；工程不自动渲染。视频/特殊格式预览取决于系统解码，不保证每种编码有缩略图。
- 无云同步、无付费服务、无自动上传。网页和 Codex 的最终上传落点仍需各自验收。
