# 一幕 YimuCraft 使用说明

## 安装与数据

1. 本机双击项目根目录“安装或升级一幕.cmd”，自动暂存安装包、校验并安装，成功后打开一幕。也可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-local.ps1 -Open`。
   本机从 K 盘直接运行安装 EXE 存在临时文件访问问题；此入口不修改系统权限。菜单“帮助→关于一幕”显示当前索引位置。
2. “文件→新建／切换素材库”选择文件夹。默认将文件复制到库内并校验，原文件保留；重复导入可跳过或保留两份。已有库可直接连接，原素材只读引用，一幕资料与缓存单独保存，无需导入素材包。
3. “备份索引”保存 SQLite；“恢复备份到新库”必须选新的空文件夹。索引备份不包含媒体原文件。
4. 软件安装与素材迁移是两件事。迁移媒体应导出素材包，不能只复制数据库或 EXE。

顶部显示“YimuCraft · 素材随取，灵感成幕。”和当前运行版本号。搜索框旁的“文件夹＋”为导入文件夹，Ctrl+I 同样可用。

## 浏览与管理

- Ctrl+I 导入文件夹；Ctrl+Shift+I 导入文件；Ctrl+V 将剪贴板图片或文件复制入库（输入框中仍为文本粘贴）。可按名称、标签、注释、格式、评分和日期筛选。
- 单击查看详情，资料填写后点“保存资料”。空白处拖动框选，Ctrl 增减选、Shift 追加，Escape 取消框选；Ctrl 多选、Shift 连选；Ctrl+A 选择当前筛选的全部素材，包括尚未加载的分页。
- 目录区空白处右键可“新建文件夹”；文件夹右键弹出操作菜单，选择重命名或新建后才显示单用途输入框。素材区空白处按当前目录新建；关联原库目录仍保持只读。
- 文件夹标题行可选“名称升序／名称降序”，旁边加号新建；导入文件夹使用顶部工具栏。
- 滚动自动加载下一批，远处卡片会卸载。左栏分类支持嵌套；分类删除保留原文件。
- 右键可发送 Adobe、定位、复制、导出和回收；Ctrl+C 复制真实文件，Ctrl+Alt+C 复制路径。
- 回收站只隐藏索引，原文件不删除。右键目录可改名、移动、创建子目录、设置图标、删除空目录或重新定位。重新定位会校验受管素材的内容哈希；旧索引无哈希且原文件已离线时仅核对大小，并明确提示。

- 直接点击分类或文件夹的小图标，可设置图案、Emoji 和颜色；也可右键进入“图标与颜色”。保存后重启保留，关联原库同样支持；仅改变一幕内显示。
- “帮助→关于一幕”可查看并复制公众号“知鸟PLAN”和个人微信“aizzn2030”。

## 预览与查找

- 音视频悬停预览，空格打开详情播放；Ctrl+K 设置双击行为、静音、记忆位置和托盘关闭行为。
- PSD/PSB、EXR、DPX、TIFF 等图片会自动生成预览；AVI 等可右键选择“素材操作→生成兼容预览”；会生成独立预览，不改写源文件。
- 音频卡片显示波形、播放进度和时长，悬停默认有声，点击波形任意位置立即跳播，左右键调整 1 秒；不再显示重复滑块；音频静音独立于底部视频静音。大文件通过流式分析生成波形，缓存重启复用。
- “工具→建立色彩与相似图索引”分析图片或封面；随后用“色彩”筛选或右键“查找相似图片”。
- 相似图按低分辨率颜色和布局排序，最多返回 200 项；此入口使用像素算法。另有独立的本地 AI 语义入口；换封面后重新建立对应索引。

## AE 联动与工程迁移

1. “Adobe→检查 AE 连接”，必要时选择 AfterFX.exe。AE 需允许脚本写文件与访问网络。
2. 选择图片、音视频或 AEP/AEPX，右键选择“发送到 AE”；收到 AE 回执才显示成功。
3. 选择 AEP 导出文件夹或 ZIP 时，软件在独立 AE 进程收集依赖、重链并保存工程。
4. 将素材包复制到新位置后导入，选择工程右键选择“素材操作→AE 工程检查”；缺失依赖会显示失败。
5. 先用“Adobe→安装一幕 AE 打包面板”，重启 AE，从“窗口→一幕工程打包”打开。面板基于 ScriptUI，可停靠，不依赖旧 CEP 或 Startup 队列。
6. 保持一幕打开，在 AE 保存工程，点“打包当前工程并回库”或“打包选中合成并回库”。仅操作工程副本，完成后恢复原工程；桌面校验完整依赖再自动入库。未保存修改会被拒绝。
6. 字体应用需要字体已经激活，并选中 AE 文字层；支持保留文字内容和时间的关键帧字体修改。字体和第三方插件不随包分发。

AE 收集覆盖原生文件依赖、数字序列与代理。表达式、插件参数中的外部路径未重写。
操作超时不表示宿主停止执行；界面会保留请求 ID 并阻止紧接着重复提交。

## PR 联动

1. 通过“Adobe→安装一幕 PR 面板”安装扩展，重启 PR，再从“窗口→扩展”打开“一幕 YimuCraft”。
2. 当前使用本机未签名 CEP；本机调试开关此前已开启，干净电脑部署尚未验收。
3. PR 打开工程和活动时间线后，选 MOGRT 右键选择“发送到 PR”，选择目标视频轨后，在播放头位置插入。
4. 播放头之后已有片段的轨道会被拒绝；活动时间线或播放头改变时需重新发送。轨道选择、占用拒绝和原生插入已在独立工程实测。

5. CUBE：先在 PR 时间线选中视频片段，再在一幕右键发送到 PR；为每个所选片段添加独立 Lumetri，不覆盖已有调色。当前尚未复刻原版调节图层插入流程。

## 素材包边界

- 一幕 v2 素材包携带文件哈希、封面／样片、标签、评分、收藏、注释和嵌套分类，兼容旧 v1 包。
- 新包必须放在源目录之外；已有目标不会覆盖。损坏文件、越界路径和循环分类会被拒绝。
- Aetodo .aetodopack 有独立导入/导出入口；已测一幕 PNG 包被原版读取及真实 AE 工程搬家。原版反向导出包、全部版本变体未实测。

## 预设、脚本与重命名

- 单选 FFX 发送到 AE，会对活动合成的选中图层应用一次预设。
- 单选 JSX/JSXBIN 发送到 AE，会先显示文件路径和执行确认；只有宿主完成才记为成功。
- F2 或右键重命名会实际修改磁盘文件名，保留扩展名、标签和库内关联；已有同名文件不会覆盖。
- 重命名需要文件系统支持硬链接；支持仅修改大小写。其他工程引用的外部文件名不会自动改写。


## 本地 AI 搜索和标签

- “工具→AI 模型与标签”下载固定版本 Chinese-CLIP q8 模型（约 191 MB）；模型和图片计算均在本机，无云端图片上传。
- 建立语义索引后，将搜索方式切到“AI 语义”，输入中文画面描述并按 Enter；结果按模型相关度排列，最多 200 项。
- 右键“AI 以图搜图”使用当前素材向量；“工具→以图搜图”可选外部图片检索当前库。
- 在 AI 设置中编辑候选标签，选素材后执行追加；原标签保留。识别有误可在资料栏修改，不把相似度当事实。
- 更新图片或封面后重建索引会跳过未变化项；取消保留已完成项。模型加载失败会明确报错，不回退为普通文字匹配。

## 新增操作

- Ctrl+A 选择当前筛选的全部素材，包含尚未滚动加载的项；改变筛选会清除旧选择。
- TTF/OTF 详情可安装到当前 Windows 用户。已有同名字体会提示检查版本，避免覆盖。
- OBJ、STL、FBX 基本几何、内嵌 GLB/glTF 自动生成缩略图；详情可旋转、缩放、平移和将当前视角设为封面。OBJ 暂不加载 MTL，C4D、外部贴图、动画控制与 Draco 压缩未支持。
- PDF 兼容 AI/PDF 自动预览第一页；旧式非 PDF AI 会明确提示。RAW 显示内嵌 JPEG，不进行完整显影；无内嵌预览的文件需默认应用打开。

- 来源网址保存后可在系统浏览器打开；随一幕包保留，原版包的相应字段兼容性未验证。
- 字体详情支持短句/文章、字号和自定义文字记忆；GIF 详情可暂停与拖动帧进度。

播放器获得焦点时，空格切换播放/暂停；PageUp、PageDown 暂停并前后移动 1/30 秒。此为固定时间步长，不承诺可变帧率素材的逐帧精确导航。

## CUBE 调色预览

- 导入 CUBE 后选择“LUT 调色”类型。左侧是原图，右侧是真实 LUT 运算结果，默认使用测试色卡。
- “更换 LUT 参考图”选择 PNG/JPEG/WebP；对比图存入库内，参考原图离线后仍保留。
- 支持独立 1D 和 3D CUBE；组合 LUT、超出限制或损坏数据会明确报错。RGB 预览不代表 PR 的色彩管理结果；所选视频片段的 PR LUT 应用已实测，原版调节图层流程仍未对齐。

## 界面操作

- 点击“筛选”展开类型、标签、日期和子目录等条件。
- Adobe 发送在素材右键；导出在“导出…”子菜单；批量资料和分类在“整理素材”；取封面、字体和 LUT 参考图在“素材操作”。
- 图标改为自有抽象取景/播放图形，不含“幕”字；深色暖灰和浅色奶油白均采用陶土橙强调色。

## 连接已有素材库

- “文件→新建／切换素材库”直接选原库根目录；目前识别 data/aetodo.db 与 source/preview 结构，不需先导出包。
- 一幕建立独立索引，保留可映射的分类、标签、评分、收藏、注释、预览。原数据库和媒体不改写；标签等后续修改仅保存于一幕，不与旧软件双向同步。
- 初次连接需要读取全库；后续打开复用索引。缺失文件仍保留记录；原库路径须保持可访问。外部引用不支持原地重命名或永久删除。
- 常用菜单只保留一幕文件夹包与 ZIP；旧格式兼容代码仍保留在内部，不删除磁盘上的旧包或原软件。
