# 一幕 YimuCraft 使用说明

## 0.7.74 本机版 · 重命名素材库文件夹

右键文件夹选「重命名」，或点选文件夹后按 F2。输入新名，按 Enter 保存。连接库和外部引用目录的显示名称保存在一幕索引中，可用于排序、筛选和拖拽。重新输入磁盘原名可恢复最初显示。

一幕托管目录沿用磁盘重命名，同步更新素材索引。索引 v3 升级至 v4 时先生成快照；退回 0.7.73 请在独立目录恢复升级前快照。

## 0.7.73 整理素材库文件夹

按住左侧文件夹的图标或名称，拖到另一文件夹的高亮行后松手。目标展开，整个分支一起移入。拖到顶部「文件夹」标题可移回根目录，按 Esc 或在列表外松手可取消。

选中父级时，「筛选 → 显示子文件夹内容」控制是否包含子级素材。拖放后的层级保存在当前库的一幕索引中，磁盘文件、已连接的原库和素材引用路径保留原位。

## 0.7.72 找素材

- “找素材”位于“项目画布”下方；默认沿用当前本地项目仓库，可从下拉切换已关联仓库。空仓库可直接打开项目文件夹。
- 输入名称、标签或说明中的关键词，可继续输入“横屏”“只看已确认”“不要人物”等；条件显示为可删除标签。退回上轮、历史和新查找均在页内，空输入按 `/` 打开命令。
- “以图找”选本机参考图，或在预览中“以这张图找”，按颜色与布局相似度排序；范围超过 500 张时先筛选。此页未接通大模型语义理解，也不搜索“素材库”工作区全库。
- 勾选后可对比 2–4 项、将最多 200 项加入命名候选组；跨轮已选项保留。候选组创建独立引用，不移动原有节点；进入画布后可撤销本次入组。
- 查找历史、条件和选择按项目在本机保存；候选组随画布保存。序列可预览，须在画布展开后选择帧入组。详见 [实现与验收边界](CANVAS-DISCOVERY-20261106.md)。

## 本机 0.7.71：项目仓库

- 点击左侧“来源” → “打开项目仓库”，选文件夹；已有仓库显示缩略图、名称与数量，点击卡片直接切换，悬停查看完整路径。
- 卡片右侧 × 从列表移除；原文件与编排保留，重新打开同一路径可恢复。移除当前仓库会自动切到剩余仓库，全部移除后可重新打开。
- 顶部不再重复显示项目路径、关联按钮与搜索；画布搜索移至“筛选”。来源内的搜索只筛选待加入素材，导入功能不变。
- 离线仓库保留记录，目录恢复后点“同步”；当前不提供仓库元数据永久清空。验收与回退边界见 [记录](CANVAS-REPOSITORIES-20261105.md)。

## 本机 0.7.70：左侧快捷功能

- “项目画布”下方的来源、分组、筛选、整理切换旁边侧栏；分组名称只显示文字与箭头，选中后只给文字和原组框强调色。
- 分组列表点击名称即可定位和选中；“未归组”快速找独立素材。“筛选”可组合类型、标签和确认状态，当前条件重启保留，“清除筛选”恢复查看范围。
- 先选择同一父组下至少两个元素，再点整理中的对齐、等高或网格；等距需三个。先预览，点“应用排列”保存，或取消；“撤销上次整理”只在当前会话有效，后续修改会阻止旧撤销覆盖。
- 组名固定字号与左下导航仍保留。完整检查、范围与限制见 [本轮记录](CANVAS-SHORTCUTS-20261105.md)。

## 本机 0.7.69：布局导航与分组

- 左下半透明导航显示当前画布布局；点击跳转，拖视口框平移，Esc 取消。右上“−”可收起，聚焦导航后方向键平移、Shift 加大步长。
- 分组名称在框外保持字号，缩小时自动省略，悬停查看全名。点击组内任意空白即可激活；拖空白或标题带动整组，子元素仍可单独选择。
- 选中分组后，点击底部“名称与颜色”或同名右键项修改；名称和颜色重启保留。双击标题也可编辑。
- 导航缓存布局，平移只更新视口框；当前筛选外的元素不显示。低缩放密集组标题可能重叠，验收和边界见 [专项记录](CANVAS-NAVIGATION-20261105.md)。

## 本机 0.7.68：紧凑来源栏

- “素材库 / 项目画布”选中状态仅用背景色区分，不显示角落小勾；键盘切换不变。
- 来源栏导入继续直接引用原件；0.7.71 起完整项目路径在仓库卡片悬停查看，不再放顶部，原引用关系不变。
- 空列表显示“暂无待加入素材”，已移除长说明；有待加入素材时照常勾选并加入。来源不可访问仍在画布状态栏提示。
- [整理方向建议](CANVAS-ORGANIZATION-DIRECTION-20261105.md) 的侧栏目录、筛选与评审仍未确认；0.7.69 已实现本轮另行指定的布局导航与分组改进。

## 本机 0.7.67：画布平移与拖动

- 单图和多选都直接在画布内拖动。按住 Alt 再拖动，才向其他应用传递原文件；普通选择/移动不显示系统 logo 与路径浮层。
- 中键/右键拖动或空格加左拖平移视图，滚轮围绕鼠标缩放，F 适合窗口；松手保存最后位置，双击素材仍打开预览。
- 平移按帧合并，屏幕外卡片减少绘制。900 图热缓存夹具的 P95 帧间隔从 42.8 降到 17.3 ms，不代表所有项目固定帧率。见 [验收记录](CANVAS-PAN-20261105.md)。

## 画布媒体预览（0.7.66）

- 双击素材打开预览。拖窗口标题移动，拖任意边缘/角改变大小；双击标题或点“最大化”切换，普通尺寸和位置自动记忆。
- 图片、视频和序列帧：滚轮缩放，中键按住拖动平移。“适合窗口”填入可用区域，“100%”按预览像素显示；键盘 `+`/`-` 缩放、`0` 适应窗口。
- 视频进度条固定在画面下方；音频使用播放控件。保存标签与文件操作在底部同一排，窄窗口自动换行。
- 兼容格式会首次生成本地预览；可能需要等待，原素材与导出路径不变。损坏、离线或不支持的编码会提示，可用默认应用打开。具体格式与缓存限制见 [预览记录](CANVAS-PREVIEW-20261105.md)。


## 本机 0.7.65：大画布多选拖动（已安装）
- 框选后直接拖选中元素即可整体移动；拖分组标题带动全部后代。松手保存，Esc 或指针取消恢复原位置。
- 0.7.67 起单张和多张图片外拖都需按住 Alt；外部传图一次最多 100 个文件。画布内多选移动不受外拖数量限制。
- 框选和拖动按显示帧合并；连线与分组高亮随位置更新。原文件不修改，已有画布格式不变。

## 本机 0.7.64：工作区与侧栏宽度（2026-10-31）
- 左侧紧凑“素材库 / 项目画布”可直接切换；0.7.68 起仅用橙色背景标识当前工作区。聚焦入口后可用上下键切换。
- 拖动文件夹栏右侧的细竖条调整宽度；双击恢复 260 px，重开保留上次宽度。
- 聚焦竖条后，左右键微调 10 px，Shift 加大为 50 px，Esc 取消正在进行的拖动。
- 侧栏最小 190、最大 900 px；窗口较窄或打开右侧详情时自动限制宽度，空间恢复后还原设定。
- 交互检查与验收边界见[修复记录](SIDEBAR-UI-20261031.md)。

## 画布传图（0.7.63，外部接收由用户试用验收）
- 图片不再有悬浮预览和「拖出文件」按钮；双击预览，悬停/选中显示底部单行名称与尺寸，最多占元素高度 1/6。
- 右键「发送到… → 设置发送目标…」可配置 Codex、Claude、WorkBuddy、即梦或自定义程序/窗口标题；仅添加到输入框，不自动发送消息。当前已实测 Codex 收到图片，其余目标待验。
- 0.7.67 起按住 Alt 拖图片本体，移到其他程序的文件接收区后松手；无需专用按钮或先拖名称条，单图/多图都传递原文件。
- 在画布内松手保存新位置，并自动加入/离开分组；拖到外部或取消时保留原布局。原图缺失会提示，不以缩略图代替。
- 本版已通过后台回归并安装；按用户要求未操作桌面或上传到外部平台，实际接收效果由用户测试。

## 项目画布操作（0.7.61）
- 空白左拖框选，Shift 追加；中键/右键拖动或空格加左拖平移，滚轮缩放，F 适合窗口，无需切换模式。
- Ctrl+G 或右键「元素编组」自动包住所选内容；拖四边调整组框，拖标题移动整组，双击标题改名称和颜色，右键「解组」保留内容。
- 组右上方按钮折叠为名称卡，再点展开；折叠后仍能整组移动。元素拖入组内自动加入，拖出自动分离，以松手时元素中心位置判断。
- 选中后移到元素边外才出现一个跟随鼠标的 ＋；拖到已有元素连线，拖到空白处新建并连接，Esc 取消。
- 双击素材放大；在预览窗口编辑标签、恢复原比例。右键复制文件路径、打开所在文件夹或删除；删除仅隐藏，历史记录可恢复。
- 自动恢复上次项目与工作区；左侧可自动同步、勾选待加入素材、选择文件或添加来源文件夹，直接引用原件。连续编号图片合并序列，双击播放。
- 图片/视频保持原比例，悬停或选中才显示信息；顶栏添加说明和文字。完整规则与验收边界见 [项目画布](PROJECT-CANVAS.md)。

## AE 按需联动（0.7.58）

## 安装与数据

公开下载请前往 [0.7.73 开发者预览版](https://github.com/zhizhiniao/YimuCraft/releases/tag/v0.7.73-dev.1)，下载 EXE 和校验文件，放到本机磁盘后运行。升级前备份素材库索引、项目画布数据和原媒体。首次打开已有索引时会保存升级前快照。回退到 0.7.72 请在独立目录恢复旧索引。详见[版本说明](releases/v0.7.73-dev.1.md)。

新安装不附带素材或 API 配置。已有素材库请自行选择根目录，不只选择 `source`，以读取原分类和预览；一幕单独维护索引与缓存。开发者本机的 D 盘连接记录见 [LIBRARY-SWITCH-20261023.md](LIBRARY-SWITCH-20261023.md)，不是所有用户的默认路径。

1. 开发者在已有构建的源码目录双击“安装或升级一幕.cmd”，自动暂存安装包、校验并安装，成功后打开一幕。也可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-local.ps1 -Open`；只下载源码时需先构建安装包。
   本机从 K 盘直接运行安装 EXE 存在临时文件访问问题；此入口不修改系统权限。菜单“帮助→关于一幕”显示当前索引位置。
2. “文件→新建／切换素材库”选择文件夹。默认将文件复制到库内并校验，原文件保留；重复导入可跳过或保留两份。已有库可直接连接，原素材只读引用，一幕资料与缓存单独保存，无需导入素材包。
3. “备份索引”保存 SQLite；“恢复备份到新库”必须选新的空文件夹。索引备份不包含媒体原文件。
4. 软件安装与素材迁移是两件事。迁移媒体应导出素材包，不能只复制数据库或 EXE。

顶部显示“YimuCraft · 素材随取，灵感成幕。”和当前运行版本号。搜索框旁的“文件夹＋”为导入文件夹，Ctrl+I 同样可用。

## 浏览与管理

- Ctrl+I 导入文件夹；Ctrl+Shift+I 导入文件；Ctrl+V 将剪贴板图片或文件复制入库（输入框中仍为文本粘贴）。可按名称、标签、注释、格式、评分和日期筛选。
- 单击查看详情，资料填写后点“保存资料”。空白处拖动框选，Ctrl 增减选、Shift 追加，Escape 取消框选；Ctrl 多选、Shift 连选；Ctrl+A 选择当前筛选的全部素材，包括尚未加载的分页。
- 目录区空白处右键可“新建文件夹”，并可一次“展开全部文件夹”或“折叠全部文件夹”；文件夹右键仍是单项操作菜单，选择重命名或新建后才显示单用途输入框。素材区空白处按当前目录新建；关联原库目录仍保持只读。
- 文件夹标题行可选“名称升序／名称降序”，旁边加号新建；导入文件夹使用顶部工具栏。
- 滚动自动加载下一批，远处卡片会卸载。侧栏只显示“全部素材”和文件夹；分类不再占用侧栏空间，已有分类和“添加到分类”仍保留。
- 右键可发送 Adobe、定位、复制、导出和回收；Ctrl+C 复制真实文件，Ctrl+Alt+C 复制路径。
- 回收站只隐藏索引，原文件不删除。右键目录可改名、移动、创建子目录、设置图标、删除空目录或重新定位。重新定位会校验受管素材的内容哈希；旧索引无哈希且原文件已离线时仅核对大小，并明确提示。

- 直接点击文件夹的小图标，可设置图案、Emoji 和颜色；也可右键进入“图标与颜色”。保存后重启保留，关联原库同样支持；仅改变一幕内显示。分类图标数据保留，但 0.7.50 起侧栏不再显示分类管理入口。
- 0.7.54 新增“软件标识、视频特效、抽象 MG、音乐调性”分组：Pr/Ae/Ps 软件标识可重复使用；“专用类型”保留每类唯一规则。所有矢量图标支持预设色、取色器及 #RRGGBB 色值；Emoji 保持原色。
- 0.7.55 新增“自媒体平台”：抖音、TikTok、快手、小红书、微信公众号、B站、微博、知乎、Instagram、YouTube、Facebook、X、Threads、Pinterest、LinkedIn、Telegram、Twitch。选择后保存即可作为文件夹图标；可重复使用、改色，默认色恢复平台识别色。
- 0.7.56 软件标识补充Final Cut Pro、达芬奇、剪映、CapCut、Blender、Cinema 4D、Illustrator、Audition；“三维与格式”提供OBJ/STL/FBX/GLB/glTF/MTL/贴图等分类图标。图标只用于分类，不表示支持打开这些软件的原生工程。
- “帮助→关于一幕”可查看并复制公众号“知鸟PLAN”和个人微信“aizzn2030”。

## 预览与查找

- 音视频悬停预览，空格打开详情播放；Ctrl+K 设置双击行为、静音、记忆位置和托盘关闭行为。
- PSD/PSB、EXR、DPX、TIFF 等图片会自动生成预览；AVI 等可右键选择“素材操作→生成兼容预览”；会生成独立预览，不改写源文件。
- 音频卡片显示波形、播放进度和时长，悬停默认有声，点击波形任意位置立即跳播，左右键调整 1 秒；不再显示重复滑块；音频静音独立于视频静音，两项默认值均可在“偏好设置 → 播放预览”修改。大文件通过流式分析生成波形，缓存重启复用。
- “工具→建立色彩与相似图索引”分析图片或封面；随后用“色彩”筛选或右键“查找相似图片”。
- 相似图按低分辨率颜色和布局排序，最多返回 200 项；此入口使用像素算法。另有独立的本地 AI 语义入口；换封面后重新建立对应索引。

## AE 联动与工程迁移

1. “Adobe→检查 AE 连接”，必要时选择 AfterFX.exe。AE 需允许脚本写文件与访问网络。
2. 选择图片、音视频或 AEP/AEPX，右键选择“发送到 AE”；收到 AE 回执才显示成功。
3. 选择 AEP 导出文件夹或 ZIP 时，软件在独立 AE 进程收集依赖、重链并保存工程。
4. 将素材包复制到新位置后导入，选择工程右键选择“素材操作→AE 工程检查”；缺失依赖会显示失败。
5. 先用“Adobe→安装一幕 AE 打包面板”，重启 AE，从“窗口→一幕工程打包”打开。面板基于 ScriptUI，可停靠，不依赖旧 CEP 或 Startup 队列。
