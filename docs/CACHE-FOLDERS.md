# 媒体缓存目录与切换

本机版本：0.7.78，2026-11-15 完成安装验收。入口：**偏好设置 → 文件夹管理**。尚未公开发布。

## 已确认的范围

- 所有素材库共用一个媒体缓存根目录，根目录内按素材库分子文件夹，包含波形、兼容试听、封面与视频预览。
- 项目画布另用一个独立缓存目录，包含 previews 和 thumbnails，便于单独清理；不把长期素材库缓存与画布缓存混放。
- “重新生成”只处理已有缓存对应的素材，不全库重建。AI 模型、索引数据库、原素材及画布编排不随本功能搬移。
- 当前没有替用户选择新的真实目录；旧版默认位置继续使用，用户选择目标并确认操作后才切换。操作确认后立即生效。

例如可在素材附近建立：

```text
D:\创作素材\原始素材\…
D:\创作素材\一幕缓存\素材库\…
D:\创作素材\一幕缓存\项目画布\…
```

两个缓存目录必须独立，不能相同或互相包含；目标需为空文件夹，避免覆盖现有文件。
缓存根目录有一幕标记，素材导入与项目扫描会跳过它，避免把生成的预览再次当成新素材。
旧版默认画布父目录还包含 projects.json 编排记录；清理请使用设置中的操作，不要手工删除整个 project-canvases 父目录。选定新的独立空目录后，该自定义目录仅存媒体缓存。

## 切换时的三个选择

| 选择 | 实际行为 |
| --- | --- |
| 删除 | 清除旧波形、试听及预览，在新位置按需生成；自设封面会恢复默认。原素材、标签、评分与画布编排保留。 |
| 重新生成 | 只重建已存在缓存对应的音频、视频与画布预览；自设封面、不能自动重建的宿主渲染预览保留迁移。原素材离线或生成失败时保留旧目录与旧缓存。 |
| 将现有缓存剪切到新路径 | 先复制并逐文件校验 SHA-256，更新预览引用与目录设置成功后再移除旧文件；跨盘采用同一流程。 |

生成与预读任务在切换前暂停；迁移期间阻止新缓存任务，完成后重新载入列表/画布。
取消在当前文件完成后生效；若旧文件被占用或发生变化，旧副本可能暂留，结果会提示，不冒充已全部清除。
旧素材库自带且位于原版库中的预览保持原路径；不移动/删除原版 Aetodo 数据。未连接、无法访问的历史库不做越界扫描。

## 性能取舍

之前默认 C 盘，是沿用 Electron 的应用数据目录，未检测该盘是不是 SSD。[Electron 目录说明](https://www.electronjs.org/docs/latest/api/app)
机械硬盘也可用；同一物理盘同时读原片、写预览时，可能受寻道和带宽竞争影响。不同目录或不同盘符不必然代表不同物理硬盘。
已生成的小波形/低码率预览通常负担较轻；首次转换、大文件和多项并发可能更明显。本轮未测用户机械盘的实际速度，不承诺差距百分比。
速度优先时可用独立 SSD/NVMe；管理优先时可选择素材附近的机械盘目录。[Adobe 缓存存储建议](https://helpx.adobe.com/premiere/desktop/get-started/technical-requirements/storage-recommendations.html)

## 实现与失败保护

- cache-locations.cjs 管理两个根目录、已登记素材库及迁移日志；cache-index.cjs 只改预览/封面引用，不改素材路径和用户分类信息。
- 新文件先进入目标盘的独立暂存目录，复制校验完成后发布；索引和设置尚未提交时，旧缓存仍在。
- 迁移日志记录提交状态；索引已改而设置未落盘的进程中断，会在下次启动恢复旧引用。设置已提交后只补做旧缓存清理。
- 删除前核对旧文件的大小、修改时间、实际路径与复制摘要；链接、非空目标、两类目录互相包含会被拒绝。
- 视频清单记录的输出时间随复制后实际文件时间更新，避免跨盘复制的时间精度差异导致重复转换。
- 新根目录不可用时不自动改写到 C 盘；迁移/重建会明确报错并保留旧数据。数据盘重新连接后可重试。

## 边界与回退

这是媒体缓存管理，不移动 Chromium 自身的 GPU/网页缓存或 AI 模型。默认旧库位置不强制自动迁移。
磁盘断连、长期占用、用户手工改写旧缓存等情况可能保留旧副本；迁移恢复冲突会停下报告，不覆盖原素材。
没有对所有文件系统、NAS、所有宿主格式或真实断电做穷举测试；测试故障为受控进程退出。
可用保留的 0.7.77 回退应用；自定义路径功能需 0.7.78，建议先在设置中迁回默认位置再回退，避免旧版无法识别自定义位置。

经验候选（待确认）：行动=目标盘暂存、校验、引用提交与中断恢复；结果=隔离测试和跨卷验证保留原件/可用预览；原因=跨盘剪切不能依赖单次 rename，缓存邻近原素材还需防止重复扫描；验收=所列回执；反例=先删旧文件、把缓存目录再次入库、忽略时间精度导致重算；边界=所测 Windows 本机及受控故障，未升级知识库经验。
