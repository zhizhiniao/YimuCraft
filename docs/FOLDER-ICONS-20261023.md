# 文件夹图标与改色

2026-10-23 America/Denver。用户确认用于一幕文件夹图标，要求更多选择、统一风格并支持改色。

## 已实现

- 新增 27 个选择：3 个软件字母标识、8 个视频特效、8 个抽象 MG、8 个音乐调性；原有 18 个基础图标和 Emoji 保留。
- 软件标识单独一组：Premiere / Pr、After Effects / Ae、Photoshop / Ps。沿用现有字形绘制，可重复用于多个文件夹。它们是应用内可改色标签，不宣称为 Adobe 官方 Logo 资源；参考产品名称见 [Adobe Creative Cloud](https://www.adobe.com/creativecloud.html)。
- 特效：光束、闪光、粒子、转场、故障、速度线、关键帧、遮罩。MG：轨道、波纹、循环、形变、流体、点阵、螺旋、飘带。
- 音乐：舒缓、律动、史诗、悬疑、轻快、梦幻、暗黑、钢琴。图案使用一致线宽、圆角、单色与少量半透明填充，维持现有暖灰界面。
- 支持预设色、原生取色器、HEX 输入；实时预览、取消不保存、非法 HEX 阻止保存。Emoji 仍保留自身颜色。
- 修复既有 Pr/Ae/Ps/音频专用类型总以默认色覆盖用户颜色的问题。旧专用类型唯一规则保留；新增软件标识没有该限制。

## 操作

点击文件夹图标，或右键“图标与颜色”→选择分组及图案→选择颜色→保存。仅更改一幕内显示，不改原目录、文件或文件系统图标。

## 工程

修改 appearance.js、appearance-picker.js、style.css；无数据库结构迁移。复用现有颜色校验与持久化；新增图标只含内置 SVG，不接受用户 SVG 脚本。按 UI、输入校验、持久化及安装主题审查。

回退可用 0.7.53 安装包；旧版不认识新增图标时显示普通文件夹，原图标 ID 仍存于库内，重装新版恢复识别。颜色格式兼容。

经验候选：行动是同时检查数据库色值和浏览器实际颜色；结果发现值虽保存但专用类型渲染覆盖；原因是默认色优先级错误；验收为 computedStyle 与完整重启；反例为仅查数据库；边界为本地图标渲染，不代表其他品牌图标支持改色。未经确认不固化。
