## 问题与实现

- 原版一幕 0.7.50 已有批量菜单，但只挂在列表空白区；满屏目录时底部空白难到达，行缩进被直接忽略。当前增加标题区域和行缩进右键命中，文件夹按钮保留单项目录菜单。
- `state.collapsed` 原来每次启动都是空集合，未持久化。现在以当前库规范化路径为键，逐次将折叠路径集合写入本机 localStorage，并在首次渲染该库前恢复；空数组表示明确全部展开。
- 构建完整目录树后再筛选显示，批量折叠覆盖未匹配的分支。单项开关增加 `aria-expanded`，叶节点不再有可点击的空开关。
- 不新增 IPC、外部服务、权限或数据库迁移。首次无记录沿用展开默认；损坏记录回退，保存失败显示错误。目录改名/移动后的新路径不继承旧路径状态，本次不扩展为目录身份迁移。
