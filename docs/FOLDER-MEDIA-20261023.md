# 文件夹入口与透明、音频预览（0.7.42）

日期：2026-10-23（America/Denver）。用户授权改为自定义目录，并用真实文件验证。

## 使用与行为
- 四个图标改为快捷文件夹：首次点击选择位置，右键更换或解除绑定；文字显示实际目录名，悬停显示完整路径。各入口可指向相同目录，不限制文件类型。
- 绑定按素材库分别保存于 folder-shortcuts.json；仅索引原位置，不移动、复制原素材。打开入口扫描新增文件；已有标签、样片关联不重置。解除绑定不删除素材。
- PNG/SVG 等图片及 MOV 卡片、详情使用 #353535 / #454545 棋盘格。背景在界面绘制，不烘焙进媒体。旧 JPEG MOV 缩略图改存透明 PNG，复用视频缓存。
- 波形继续由 FFmpeg 流式解码、缓存；试听优先原文件。无法直接播放时自动生成 48kHz 双声道 FLAC 试听缓存，原始精度与格式保留于原文件，发送/导出仍用原件。
- 兼容缓存按路径/大小/修改时间失效，最多同时两项；退出终止子进程，失败不留下半成品。鼠标离开后即便缓存完成也不自动发声。

## 验证
- 原始素材：用户真实旁白录音 WAV、真实 10.1.mov；在独立库用副本测试。为覆盖编码，真实旁白截取八秒制作 PCM24/96k WAV、float32/192k WAV、FLAC24/96k、ADPCM WAV。不是录制设备原生 192k 样本。
- 源码 UI 通过四组真实波形、悬停播放时间推进、非静音状态、点击定位、移开停止；ADPCM 实际触发自动兼容，其余三组直接播放。并人为断开一条原播放地址验证 IPC 回退。
- 文件夹首次绑定/取消/更换/空目录/重启/离线报错/解除绑定通过；混合七个文件均可从各入口看到。既有 MOV 样片未被绑定动作重置。
- 已查看透明黑色 PNG、透明 MOV 和文件夹截图；旧 JPEG 封面更新 PNG、原视频缓存复用通过。原始文件与全部测试媒体 SHA256 前后一致。
- 核心与最终构建门禁 91/91；目录版、正式安装版全套专项通过。75 个 src 文件与安装哈希一致，501 项正式素材字段和偏好不变。证据目录：evidence/folder-media-20261023/，每次 UI 使用独立运行 ID。

## 失败与边界
- 首次夹具假定正式库 MOV 有封面，实际为 null，改为从原视频生成隔离封面；未改产品规避问题。
- 第二次夹具在已成功回退的同一播放器上再人为破坏地址，触发单次回退保护。改为对尚未回退的 PCM 卡测试；保留全部失败日志。
- 原生选择框与右键菜单由自动化拦截返回路径/调用真实菜单回调；不宣称人工鼠标验收。实际扬声器听感、所有音频变体、大目录扫描速度仍未验收。
- 首次解码或兼容缓存需时间；损坏文件无法保证播放。FLAC 试听缓存只是兼容代理，不代表无重采样或原始监听品质。
- 仅本地安装，不发布 GitHub，不修改原 Aetodo、Adobe 工程、用户原素材。没有新增外部网络/服务，审查限于本地索引、IPC、缓存、UI 和升级。
