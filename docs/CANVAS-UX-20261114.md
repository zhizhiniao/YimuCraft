# 找素材与画布交互修订 · 0.7.76

## 行为与范围

- 找素材首次默认搜索当前素材库；下拉可切换项目及其已添加来源。名称、路径、标签、备注均可匹配，不要求先打标签。
- 横竖屏读取原文件尺寸。素材库分批读取，每批最多检查 500 个候选，并在约 1.5 秒后分段返回；未扫完显示“继续查找”，不把当前命中数当作全库总数。
- 顶部显示搜索框、当前条件和结果。重复条件不新增历史；历史只在主动打开时显示。“已确认”仅用于项目范围，不等同素材库收藏。
- 素材库“按画面找”和“以图找”复用现有本地语义索引，最多返回 200 项；未下载模型或未建索引会提示。项目以图找沿用最多 500 张的像素相似度比较。
- 素材库结果可加入所选项目的候选组。候选组和来源引用一次事务保存；验证失败不创建半成品，不移动原文件。
- 新建入口统一为“文字”；旧说明仍可编辑。双击在节点内改正文；旧自定义标题保留。Ctrl+Enter 或点击外部保存，Esc 取消，颜色在紧凑工具条中修改。
- 连线可通过鼠标靠近后的 × 断开；点线后按钮保留，也支持 Delete、键盘 Enter 和原右键入口。
