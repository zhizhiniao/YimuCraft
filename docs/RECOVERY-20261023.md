# PR 未决操作与数据库升级恢复

日期：2026-10-23。版本：0.7.40。仅本机更新，不发布 GitHub。

## 修改范围

- PR 请求在发出前持久化请求 ID；超时、进程重开、迟到或损坏回执均不能自动解除锁定。排队未执行的请求在超时时取消；已执行请求不自动重发。
- Adobe → 处理 PR 未决操作：可靠回执须人工核对后解锁；未知结果须先保存并关闭 PR，再人工确认。取消保留记录，解除只归档，不重放请求。
- 恢复入口同时检查面板心跳和 Windows 进程；读取失败保留锁。面板在线时禁止未知结果解锁，并在确认对话框后再次检查。
- SQLite 引入 user_version=1。旧库先 VACUUM INTO 一致性快照并检查完整性，再用单一事务迁移。异常或进程中断回滚未提交修改；拒绝较新 schema。
- 不自动拿旧备份覆盖当前库。快照通过“文件 → 恢复备份到新库”恢复到空目录；媒体仍需原路径文件，索引快照不是素材包。
- 同时交付此前六项工程审查修复。按任务路由检查 Adobe 重试、迁移、备份恢复及打包升级；没有扩展登录、收费或云服务。

- 首次完整测试 89/90：把既有素材分类修复误移入一次性迁移，导致重启分类回归。已恢复每次启动分类处理；专项 20/20、随后完整 90/90。

- 所有失败日志保留；不将本轮通过扩大为 PR 全格式、全宿主版本或原版 1:1 验收。

## 回退与边界

源码回退须仅撤销本轮改动，保留开工已有功能；不得 reset 工作树。旧索引保存在 evidence 与库内 schema-backups；需要恢复时先退出写入者，恢复到新目录核对，再选择使用。不得直接覆盖当前库或删除 WAL。

经验候选：行动是同时制造“宿主已执行但回执延迟”和迁移中途退出；结果暴露重复提交、分类回归及进程漏报；原因是正常成功路径无法覆盖未知结果；验收用真实宿主计数、文件快照和重启；反例是只检查 busy 或备份文件存在；边界是本机环境及明确夹具，未经确认不升级为通用经验。
