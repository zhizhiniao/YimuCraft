## 当前引导：十步，包含三个工作区

1. 素材库：高亮并切到素材库，说明长期管理、分类和统一检索。
2. 导入、浏览和预览：说明引用/复制、文件夹范围和资料。
3. 项目画布：切到真实画布，说明项目仓库、加入画布、分组/文字/连线、AE/PR 联动及与素材库的关系。
4. 找素材：切到真实检索页，说明素材库/项目范围、关键词与筛选、预览及加入画布。
5. 本地 AI：回到素材库，显示是否下载、已索引量，打开真实面板，指引下载模型及建立画面索引。
6. API 设置：打开真实设置面板，说明加密 Key、外发媒体、计费和视觉/音频能力要求。
7. 顶部模型切换：解释当前服务商/模型；文件夹分析仍以其独立配置为准。
8. 文件夹小样与自动打标，明确确认后再批量；未选文件夹给出提示。
9. 按标签/说明查找，区分文字与 AI 语义的准备条件。
10. 完成、帮助重开与检查更新。

引导可以打开实际配置面板，关闭面板后回到当前步骤。保留上一步、下一步、跳过。旧引导的完成状态保留，需要从“帮助→新手引导”查看新增内容；不会每次升级强制重弹。
引导不会自行下载 191 MB 模型、建立全库索引、保存 Key 或发送分析请求。本地 CLIP、API 图片理解与真实音频理解的边界已明确；暂无音频服务时继续跳过。
工作区切换复用现有界面逻辑，等待启动时的工作区恢复完成；切换过程中禁用前后步按钮。不会替用户选择项目目录、导入项目或编辑编排。

## 哪些用户能收到更新提示

**0.7.79 及更早版本没有检测逻辑，不能因 GitHub 出现新包而自行获得提示。** 这些用户必须先手动安装一次 0.7.80 或后续含检测功能的版本。新版本仍须由项目发布到官方 Release，本机打包不等于已公开。

- 0.7.80 起，默认启动 15 秒后向官方 GitHub Release 查询一次；成功后 24 小时内启动不重复查。
- 发现更高的主/次/修订版本时，显示非模态“发现新版本”提示；“帮助→检查更新…”可随时手动查询。
- 官方发布目前使用开发者预览，检测包含非草稿预览版本，并明确显示预览标记。相同主/次/修订号不因 `dev` 后缀变化提示；每次分发更新需要递增应用版本号。
- 可关闭自动检查或跳过该版本；跳过只影响同一版本，更新的版本仍会提示。偏好存于用户数据区 `updates.json`。
- 下载按钮只打开本项目官方版本页，用户自行下载并运行安装包。当前没有后台下载、自动退出安装或静默替换功能。
- 查询只传公开版本请求与应用版本 User-Agent，不上传素材、路径或 Key。网络失败、限流、异常响应显示明确状态，不误报“已经最新”，不影响素材库。

实际官方源核验：[当前公开版本 0.7.76-dev.1](https://github.com/zhizhiniao/YimuCraft/releases/tag/v0.7.76-dev.1)，回执 `work/onboarding-updates-20261115/official-feed.json`。因此本机 0.7.80 当前应显示“没有更新版本”，不能伪造公网升级提示。
