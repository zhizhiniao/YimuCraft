## 大体量模型：讨论结论

已有主文件64 MB、外部资源合计256 MB/1000项限制。这些是文件门槛，不是GPU内存保证；少量压缩文件也可能含高面数、巨大贴图或大量节点，当前缺少完整的面数/解码像素/解析超时硬限制。

建议下一步采用“列表优先静态封面、点击后才交互；复杂模型只显示格式与大小，用原软件打开”。更可靠的轻量判断需要三角形数、纹理解码预算及可终止的解析流程，不能只承诺某个MB以下一定流畅。以上为方案讨论，本轮未改为全面按需加载或新增阈值。
