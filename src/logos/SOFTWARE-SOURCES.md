# 软件标识补充

Resolve、Blender、Cinema 4D、Illustrator、Audition 使用 Simple Icons 13.0.0 的静态 SVG path（CC0 图形集，非本项目官方授权声明）：https://github.com/simple-icons/simple-icons/tree/13.0.0/icons 。

Final Cut Pro 为本项目绘制的单色场记板识别图案；剪映/CapCut 为本项目绘制的单色交叉剪辑带识别图案，非官方图标原文件。统一适配文件夹小尺寸和改色。产品参考：https://www.apple.com/final-cut-pro/ 、https://www.blackmagicdesign.com/products/davinciresolve 、https://www.capcut.com/ 。

三维与格式8个图形为本项目绘制；格式图标只帮助分类，不表示新增对应软件或原生工程预览能力。
