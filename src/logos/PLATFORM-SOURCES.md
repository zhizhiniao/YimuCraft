# 自媒体平台图标来源

图形取自 Simple Icons 13.0.0（CC0 图形集），不是本项目自称的官方授权素材。平台商标归各自权利人；用于用户本地文件夹分类。代码只内置校验后的静态 path，不加载远程 SVG。

统一单色、同尺寸；默认使用适合深色界面的识别色，不保证与品牌标准色完全相同。抖音与 TikTok 共用音符轮廓，名称与默认颜色区分；公众号使用微信识别标志。用户可改色。
